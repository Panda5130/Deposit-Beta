# Merger Adjustment Log

Generated by `data_build/build_dataset.py`.

## Method
- Deposit rate = 400 x quarterly deposit interest expense (FDIC `EDEPDOMQ` + `EDEPFORQ`) / average of current and prior quarter-end total deposits (`DEP`).
- Mode A (predecessor deposits >= 1% of survivor deposits at the last pre-merger quarter): predecessor deposit interest expense and deposits added to every pre-merger quarter; merger quarter gets the predecessor's last quarterly interest expense pro rata to the days before the effective date. Applied recursively to predecessors' own Mode A events.
- Mode B (< 1%): flagged in the merger quarter, no adjustment, rows kept in `rate_pf_clean`.
